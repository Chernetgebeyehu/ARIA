# ARIA – Android AI Assistant

ARIA is an Android-based AI assistant inspired by JARVIS and FRIDAY.  
It is designed to make artificial intelligence more visual, interactive, and accessible.

## Features
- Voice interaction
- Wake word detection
- Floating assistant interface
- Accessibility service integration
- App control and automation
- Security analysis features

## My Vision
I built ARIA to explore how AI can become more useful and accessible, especially for communities with limited access to advanced technology. My long-term goal is to support local languages such as Amharic and make AI more practical in Ethiopia.
